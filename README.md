## What is Orbit?

Apple's Continuity — Handoff, Universal Clipboard, AirDrop — only works between Apple devices. If your phone and your PC aren't both wearing the same logo, you're stuck emailing files to yourself.

**Orbit fixes that.** It's a fast, always-ready bridge between your phone and your computer — clipboard sync, direct file transfer, and full remote control — that works no matter what's on either end.

> Not a remote-desktop app. No screen mirroring, no lag-fest video streams. Just the invisible, instant handoff your devices should've had all along.

#### 📋 Clipboard & Continuity
- Bidirectional clipboard sync — copy anywhere, paste anywhere
- Clipboard history across devices
- "Continue on PC" — resume browsing/media from the same spot
- Auto-detect nearby device, zero manual pairing after first setup

#### 📁 File Sharing
- Direct phone ↔ PC transfer, no cloud middleman
- Native share-sheet integration
- Drag-and-drop on desktop, instant thumbnail previews
- Auto-organize by file type, send-to-print, photo auto-backup

#### 🚀 App Launcher
- Customizable grid — launch any PC app, shortcut, or URL from your phone
- Context-aware layouts, "scenes" for one-tap workflow setup

#### 🖱️ Mouse & Keyboard
- Full touchpad with multi-touch gestures, gyroscope mode
- Complete keyboard input, modifier combos, custom macros

#### 🔊 Sound, Power & Display
- Volume mixer, output switching
- Shutdown / restart / sleep / lock / Wake-on-LAN
- Brightness and display mode control

#### 🔐 Security First
- QR pairing, biometric confirmation, per-device permissions
- Full activity log, one-tap panic lock

## Architecture

<div align="center">

<!-- 🖼️ BOILERPLATE: Architecture diagram — mobile app <-> WebSocket relay <-> desktop service -->
<img src="PLACEHOLDER_ARCHITECTURE_DIAGRAM.png" alt="Orbit architecture diagram" width="80%"/>

</div>

Orbit runs as two components:

- **Orbit Mobile** — the React Native app on your phone (iOS/Android), sending commands and receiving events.
- **Orbit Desktop** — a lightweight background service on your PC (Windows/Linux) that simulates input, manages files, and executes commands.

Both talk over a single encrypted WebSocket command channel — the same pipe handles clipboard events, file chunks, mouse/keyboard input, and launcher commands.

## Getting Started

```bash
# Clone the repo
git clone https://github.com/BiasManan2010/orbit.git
cd orbit

# Install desktop service dependencies
cd desktop && npm install

# Install mobile app dependencies
cd ../mobile && npm install
```

<details>
<summary><b>Full setup instructions</b></summary>
<br/>

1. Run the desktop service on your PC — it starts a local WebSocket server and begins broadcasting via mDNS.
2. Open the Orbit mobile app — it auto-discovers your PC on the same network.
3. Scan the QR code shown on desktop to pair.
4. You're connected. Try copying text on your phone and pasting on your PC.

*(Full instructions will be expanded as the project develops.)*

</details>
